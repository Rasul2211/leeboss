# LEEBOSS.TJ

Интернет-магазин мужской одежды с виртуальной 3D-примерочной.
Демонстрационная версия: заказы создаются по-настоящему, но реальных платежей не проводится.

---

## Что нужно для запуска

- **Node.js 20 или новее.** В репозитории лежит портативный Node 24 в `_tools/` — если он у вас есть, отдельно ставить ничего не нужно.
- **PostgreSQL.** Локально поднимается одной командой, без установки в систему.

## Локальный запуск

```bash
npm install

# локальный PostgreSQL в отдельном окне терминала — не закрывайте его
npx prisma dev

# скопируйте .env.example в .env и подставьте строку подключения,
# которую напечатает prisma dev
cp .env.example .env

npm run db:push     # создать таблицы
npm run db:seed     # загрузить 45 товаров, категории, зоны доставки
npm run dev
```

Сайт открывается на `http://localhost:3000`.

## Публикация на домене

Нужны два аккаунта — их создаёт владелец проекта:

### 1. База данных

Подойдёт любой хостинг PostgreSQL. Бесплатные тарифы есть у [Neon](https://neon.tech) и [Supabase](https://supabase.com).
После создания проекта скопируйте строку подключения вида
`postgresql://user:password@host/dbname?sslmode=require`.

### 2. Хостинг

[Vercel](https://vercel.com) — импортируйте репозиторий и задайте переменные окружения:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения из пункта 1 |
| `AUTH_SECRET` | случайная строка, `openssl rand -base64 32` |
| `TELEGRAM_BOT_NAME` | имя бота без `@`, необязательно |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather, необязательно |

Build Command Vercel подхватит сам из `package.json` — скрипт `vercel-build`
прогоняет миграции перед сборкой.

### 3. Первичное наполнение

Один раз после первого деплоя, с локальной машины:

```bash
DATABASE_URL="строка_подключения_продакшна" npm run db:seed
```

### 4. Вход через Telegram

Виджет Telegram не работает на `localhost` — только на настоящем домене.
После деплоя: создайте бота у [@BotFather](https://t.me/BotFather), выполните
`/setdomain` и укажите адрес сайта, затем пропишите `TELEGRAM_BOT_NAME` и
`TELEGRAM_BOT_TOKEN`. До этого на странице входа честно написано, что способ
недоступен, и работает вход по номеру телефона.

## Как устроен проект

```
prisma/          схема базы (20 моделей) и сид
public/products/ 45 фотографий каталога, 900×1200
scripts/         проверка геометрии манекена
src/app/         маршруты: витрина, кабинет, админка, панель сотрудника
src/components/  интерфейс, сгруппированный по разделам
src/lib/         работа с данными, доступ, деньги, математика манекена
_assets/         исходные фото и конвейер их обработки
_tools/          портативный Node
```

### Виртуальная примерочная

Манекен не скачан, а строится кодом: тело задаётся эллиптическими сечениями,
пропорции — долями от роста. Вес влияет через корень из массы на единицу роста,
поэтому высокий тяжёлый человек выглядит крупным, а не надутым. Одежда — оболочка
поверх тех же сечений, отодвинутая наружу на величину, зависящую от кроя и размера.
Слоты: `HEADWEAR`, `TOP`, `OUTERWEAR`, `BOTTOM`, `SHOES`, `ACCESSORY`.

`npm run check:mannequin` проверяет, что макушка совпадает с заданным ростом,
что вес меняет обхват, а телосложение перераспределяет его, и что каждая вещь
садится на свои анатомические отметки.

### Доступ

Сессия — подписанный JWT в httpOnly-куке. Права перечитываются из базы на каждый
запрос, поэтому отзыв доступа срабатывает сразу. Каждый раздел админки и каждое
серверное действие проверяют право заново: скрытая ссылка защитой не считается.

## Что осталось незаполненным

Это осознанные пропуски, а не недоделки — данных для них не было, и выдумывать
их означало бы вводить покупателя в заблуждение.

- **Состав и уход** у всех товаров пусты: на исходных фотографиях их не было.
  Поля есть в админке.
- **Верхняя одежда и аксессуары** — разделы заведены, товаров нет, ждут фотографий.
- **Семь цен** проставлены по проверке somon.tj и wildberries.tj и помечены в
  `_assets/catalog/catalog.json` флагом `priceAssumed`.
- **Шестнадцать размерных рядов** не были указаны на фото — помечены `sizesStated: false`.
- **Отзывы на товары** появляются только от покупателей с выполненным заказом.
  Семь отзывов о магазине на главной предоставлены владельцем.
